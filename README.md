ДЗ (Модуль 8)
В папке '8-weather-extended' реализовать CLI-утилиту с точкой входа 'weather.js', которая будет выводить погоду для нескольких городов, используя стороннее API (https://openweathermap.org):
1. Реализовать функциональность ввода латиницей в виде строки 'node weather.js -s [CITY1 CITY2 ...]' названий городов и сохранения в json-файл для дальнейшего использования городов по умолчанию.
2. Реализовать функциональность ввода латиницей в виде строки 'node weather.js -l [LANG]' (например, английский [EN] или русский [RU]) языка вывода информации о погоде и сохранения в json-файл для дальнейшего использования языка по умолчанию.
3. Описать функционал CLI-утилиты при вводе строки 'node weather.js -h'.

ДЗ (Модуль 18)
В папке '18-api-example' реализовать систему регистрации и авторизации для админов в проекте API:
1. Первоначальная настройка пустого Typescript-проекта, а также настройка Eslint и prettier.
2. Создание базовой структуры приложения для последующей настройки маршрутов (роутов).
3. Включить методы для регистрации и авторизации пользователей, используя логин и пароль.
4. При успешной авторизации выдавать JWT токен.
5. Добавить отдельный маршрут для проверки JWT токена и доступа, возвращая статус 200 ОК или 401 Не авторизован.
6. Добавить middleware для проверки JWT токена на роутах, требующих авторизации.
7. Покрытие приложения end-to-end тестами, сфокусированными на функционале авторизации и регистрации.
8. Тесты должны быть независимыми, с возможностью запуска отдельных тестов, включая предварительное добавление или удаление данных для теста.
9. Подключение к базе данных с конфигурацией из .env файла.
